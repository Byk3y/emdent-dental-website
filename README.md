# Remdent Dental Website

Production-ready Next.js website for Remdent Dental Clinic in Lagos.

The site includes a responsive brand-led homepage, service sections, patient proof, appointment request flow, WhatsApp booking, clinic contact details, and deployment-ready static assets.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

The app is ready for Vercel or any Next.js-compatible host:

```bash
npm run build
```

Then import the repository into Vercel and deploy from the default branch.
